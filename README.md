## 📖 Overview

**Chhabilal Cards** is western Odisha’s leading manufacturing house for bespoke wedding invitations, royal scrolls, 3D pop-up mandaps, heavy-duty office filing systems, and customized school merchandise. 

Operating from our landmark facility in **Brajarajnagar (Jharsuguda)**, we combine traditional Indian artisan techniques—such as hot gold foil embossing, metallic pearl sheet coating, and laser filigree cutouts—with high-speed modern printing equipment to deliver factory-direct wholesale pricing to families, institutions, and retailers across Odisha and pan-India.

## 🚀 Running Locally

### Prerequisites
- Node.js (v18 or higher)
- npm or bun

### Step 1: Clone Repository
```bash
git clone https://github.com/codenpixel2022-hub/chhabilal-cards.git
cd chhabilal-cards
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Launch Local Development Server
```bash
node node_modules/vite/bin/vite.js --port 3000 --host 0.0.0.0
```
Open **[http://localhost:3000/](http://localhost:3000/)** in your browser.

### Step 4: Verify TypeScript & Build Production Bundle
```bash
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build
```
